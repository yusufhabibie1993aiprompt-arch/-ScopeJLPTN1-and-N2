語彙Lab N1/N2 — Prototype PWA

Cara mencoba cepat:
1. Ekstrak ZIP.
2. Untuk sekadar melihat tampilan, buka index.html.
3. Agar fitur Install PWA / cache offline bekerja, jalankan lewat web server atau upload folder ke GitHub Pages.
4. Tombol “Muat Artikel Demo” mengisi artikel ekonomi lengkap dengan:
   - teks Jepang
   - furigana di baris terpisah
   - terjemahan Indonesia per paragraf
   - vocab target
5. Progress flashcard & quiz disimpan di localStorage browser.

Catatan:
- Ini prototype frontend lokal.
- Analisis artikel bebas, furigana otomatis lengkap, dan terjemahan otomatis natural untuk artikel kustom memerlukan modul AI/backend pada tahap berikutnya.
- Bank vocab demo berisi contoh N1/N2/Advanced lintas bidang.
